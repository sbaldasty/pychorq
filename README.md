# pychorq
Simulated quantum backend for uvm-plaid/pychor

## Quickstart

Create and activate a virtual environment, then install in editable mode with dev tools:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .[dev]
```

Run the Hello World console app:

```bash
pychorq-hello
```

Run unit tests:

```bash
pytest
```
